처음 사용하시나요?

스밍 캡처 시작하기

  1. 스밍찍 메인 화면 가운데의 시작 버튼을 누르고, 합짤 저장을 위한 사진 추가 권한을 허용하세요.
  2. 이용 시간이 없으면 보상형 광고를 끝까지 시청하세요. 스밍 감지 이용 시간 24시간이 제공됩니다.
  3. iOS 시스템 화면 공유 창에서 캡처 시작을 허용하세요.
  4. 멜론 재생 화면으로 이동해 곡명·가수·재생 시간이 보이도록 화면을 켜 두세요.
  5. 인식된 재생 정보를 바탕으로 첫샷과 마지막 샷을 합친 이미지가 앱과 사진첩에 저장됩니다.
  6. 종료할 때는 스밍찍으로 돌아와 가운데 정지 버튼을 누르세요.

스밍찍 화면을 보고 있는 동안에는 캡처를 수집하지 않습니다. 화면 구성, 알림 등으로 재생 정보가 가려지면 인식이 어려울 수 있습니다. 스밍찍은 음악을 직접 재생하는 앱이 아닙니다.

주요 기능 사용하기

합짤

이미지 확인과 수동 추가

메인의 합짤을 눌러 크게 보고, 좌우로 넘겨 앞뒤 이미지를 확인하세요. 수동추가에서는 사진이나 파일에서 1~4장을 골라 합짤을 만들 수 있습니다.

수동으로 만든 합짤은 저장 후 ‘사진 앱에 저장’을 눌러 사진첩에도 남길 수 있습니다.

스티커 · 띠배너

나만의 인증 이미지 꾸미기

STICKER → ＋ 추가에서 이미지나 텍스트 스티커를 만드세요. 끌어서 이동하고 두 손가락으로 크기와 회전을 조절할 수 있습니다.

구성을 스티커판으로 저장하고 메인에서 체크하면 자동 합짤에 적용됩니다. 윗띠배너·밑띠배너도 이미지를 선택하고 ‘붙임’을 켜서 사용할 수 있습니다.

총공 가져오기

빌지 원문이나 주소로 불러오기

총공 안내문 또는 게시글 주소를 복사한 뒤 복붙인식을 누르세요. 다른 앱의 공유 메뉴에서 스밍찍을 선택하면 인식된 목록을 확인하고 가져올 수 있습니다.

공유로 가져온 뒤에는 스밍찍 앱을 열어 목록을 확인하세요. 총공 웹페이지의 to App은 현재 총공 목록을 웹의 목록으로 교체합니다.

총공 참여

재생 목록과 알림 준비하기

총공 제목 옆 재생 버튼으로 멜론 곡 목록을 넘길 수 있습니다. 총공 카드를 누르면 제목이 복사되고 대상 갤러리로 이동합니다.

SETTING → 총공 설정 → 알람 설정에서 알림 시각을 선택하세요. 알림을 받으려면 iOS 알림 권한을 허용해야 합니다.

자주 묻는 질문

캡처를 시작했는데 합짤이 만들어지지 않아요.

시스템 화면 공유가 시작되었는지, 사진 추가 권한을 허용했는지 확인하세요. 멜론의 곡명·가수·재생 시간이 보이는 화면을 켜 두어야 합니다. 첫샷과 마지막 샷이 확보되지 않거나 인식한 재생 구간이 30초 미만이면 합짤을 남기지 않습니다.

화면을 잠그거나 다른 앱을 봐도 되나요?

안정적인 수집을 위해 기기를 잠그지 말고 멜론 재생 화면을 유지해 주세요. 다른 앱이나 잠금 화면에서는 재생 정보를 읽을 수 없어 합짤이 만들어지지 않을 수 있습니다.

광고를 봤는데 이용 시간이 없어요.

보상형 광고를 끝까지 시청해야 이용 시간이 지급됩니다. 중간에 닫으면 지급되지 않습니다. 끝까지 시청했는데도 반영되지 않으면 발생 시각과 앱 버전을 적어 문의해 주세요.

합짤을 편집했는데 사진첩의 사진은 그대로예요.

편집 결과는 앱 안의 합짤에 반영됩니다. 이미 사진첩에 저장한 사진은 자동으로 바뀌지 않으므로, 편집한 이미지를 다시 사진첩에 저장해 주세요.

앱에서 삭제하면 사진첩에서도 삭제되나요?

기본적으로는 앱의 합짤만 삭제합니다. ‘SETTING → 스밍 설정 → 합짤 삭제 시 사진첩에서도 삭제’를 켜면 연결된 사진도 함께 삭제할 수 있습니다. 사진 접근 권한과 iOS의 삭제 확인이 필요하며, 연결 정보가 없는 사진은 사진첩에서 직접 관리해 주세요.

총공 정보를 인식하지 못해요.

시간·총공명·대상 링크 등이 포함된 빌지 원문 또는 게시글 주소인지 확인하세요. 로그인이 필요한 게시글이나 형식이 다른 안내문은 인식되지 않을 수 있습니다. 주소로 가져오기가 실패하면 게시글 원문을 복사해 ‘복붙인식’을 시도해 주세요.

멜론 재생이나 디씨앱 이동이 안 돼요.

멜론 앱이 설치되어 있는지 확인하세요. 멜론 곡 ID가 없는 일정은 재생 목록에서 제외됩니다. 실제 재생 여부는 멜론에서 확인해 주세요. 디씨앱으로 이동할 수 없는 경우에는 웹페이지로 이동합니다.

권한을 다시 설정하고 싶어요.

iPhone의 ‘설정 → 앱 → 스밍찍’에서 사진과 알림 권한을 확인하세요. 앱 안의 ‘SETTING → 접근권한 안내’에서도 권한의 용도를 확인할 수 있습니다. 화면 캡처는 시작할 때 시스템 창에서 허용하며, 스밍찍의 정지 버튼 또는 시스템 화면 공유 제어에서 종료할 수 있습니다.
